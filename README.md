# Zeft

Zeft is a runtime-first template compiler and renderer written in Zig.

## Requirements

- Zig 0.16.0

## Build and test

```sh
zig build
zig build test
```

The public library module is named `zeft`. Implementation planning is in
[`docs/design/implementation-plan.md`](docs/design/implementation-plan.md),
and normative architecture requirements are in [`docs/architecture`](docs/architecture/README.md).
